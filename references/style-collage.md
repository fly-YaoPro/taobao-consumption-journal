# 动态消费拼贴手账

以 [动态拼贴固定框架](scrapbook-blueprint.md) 和 `assets/starter/scrapbook.js` / `scrapbook.css` 为当前实现基准。优先接入内容数据，不从空白重写模板。旧AI参考图继续用于理解配色与纸层，不要求每一页机械三列。

参考 https://sophiehart.framer.website/ 的大字、手写短注、相纸叠放、文件夹翻阅、实物式导航和轻动效；不复制它的人像、品牌、装饰图片或源码。大标题用包内荆南波波黑，短便签用霞鹜文楷，正文与功能文字用Noto Sans SC，不依赖用户电脑已有字体或在线CDN。字体许可随包保留。

## 首页与主题

首页顺序：大短标题与真实商品拼贴 → 记得住的物件故事 → **整页人生阶段大文件夹叠层** → 跨阶段兴趣与变化 → 计划和可选配歌。米白方格底、深色主字，紫/蓝/橄榄绿大文件夹、白色主纸、浅黄侧笺；借参考首页的图文层次和滚动关系，不只换配色。不是三张小文件夹按钮，也不退化成同款仪表盘卡片。

商品拼贴允许局部受控叠放，主相纸大、辅助图小，不能压住正文或按钮。资料少减图，缺图转真实文字，不复制同图冒充不同购买物。

三个固定主题：A主相纸＋短记；B双图对照；C来源小票/时间线＋主图。每页解释只写一次，没有原话不造巨幅引语。短回顾、发现和日期由数据驱动，不能写死相机、门铃或猫的人设。

## 三个板块与动效

始终只有回看、订单日历、计划。底部相纸/日历/文件夹导航固定，但正文预留安全空间；来源、翻页、计划操作不得被挡。手机重新排序，正文保持15—17px，标题不横向溢出。

入场分批、相纸悬停回正，大文件夹沿正常文档流sticky逐张叠上来；不强制滚屏、不截断段落。侧笺和主叙事不可重复。手机/矮屏/减少动态效果下顺序展开，键盘与触屏不依赖悬停。日历默认有记录月份；计划构建期先生成，再由便签展示和编辑，不能空着。

## 真实素材与分享

图片来自实际订单、核对过商品与规格的原平台页面，或授权同商品实拍。照片可作白边相纸，原形不改；不能拿AI参考商品、卡通或相似图库物件替代购买证据。图注写准确短名，广告字很多的图片放来源，不放大当主视觉。

分享图使用同源短结论、节点与实际覆盖；默认不带账号、订单号、精确金额或私人照片。实际导出并检查1080×1440 PNG，不将AI参考图当成真实运行效果。
