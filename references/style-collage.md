# 动态消费拼贴手账

当前字体、排版和交互以 [纸页手账](paper-keepsake-preview.md) 与 assets/starter 实现为准。

以 [动态拼贴固定框架](scrapbook-blueprint.md) 和 `assets/starter/scrapbook.js` / `scrapbook.css` 为当前实现基准。优先接入内容数据，不从空白重写模板。旧AI参考图继续用于理解配色与纸层，不要求每一页机械三列。

保留大字、手写短注、相纸叠放、阶段翻阅和轻动效的一般设计原则，不将单一外站的布局组合当作复刻目标；外部参考按 [设计与素材使用边界](design-rights.md) 核对。大标题用包内荆南波波黑，短便签用霞鹜文楷，正文与功能文字用Noto Sans SC，不依赖用户电脑已有字体或在线CDN。字体许可随包保留。

## 首页与主题

首页顺序：大短标题与真实商品拼贴 → 记得住的物件故事 → **多标签人生阶段纸页** → 跨阶段兴趣与变化 → 计划和可选配歌。沿用包内可读、分层的手账组件，不以外站配色或装饰位置为硬指标。奶油纸、墨蓝文字和少量玉米黄点题，阶段以雾蓝、鼠尾草和陶土区分。

商品拼贴允许局部受控叠放，主物大、辅助素材小，不能压住正文或按钮。按 [素材类型](media-selection.md) 选择实物、照片、封面、设计预览或服务摘要，不把广告原图统一套相纸。资料少减图，不复制同图冒充不同购买物。

三种主题：A主物＋短记；B两件对照；C来源时间线＋主物。文件夹也有 spread/ledger/contrast 不同图文比。按叙事取舍模块，解释只写一次，不用年度卡、主题卡、跨年卡三次复述同一观察。没有原话不造引语，不写死人设。

## 三个板块与动效

始终只有回看、订单日历、计划。底部编号导航固定，正文预留安全空间；来源、翻页、计划操作不得被挡。手机重新排序，正文保持15—17px，标题不横向溢出。

入场分批、相纸悬停回正，阶段纸页通过标签、前后按钮或方向键切换，轻滑进入；不强制滚屏、不截断段落。侧笺和主叙事不可重复。手机/矮屏保留顺序阅读，减少动态效果时直接切换，键盘与触屏不依赖悬停。日历默认有记录月份；计划构建期先生成，再由便签展示和编辑，不能空着。

## 真实素材与分享

图片来自实际订单、核对过商品与规格的原平台页面，或授权同商品实拍。照片可作白边相纸，原形不改；不能拿AI参考商品、卡通或相似图库物件替代购买证据。图注写准确短名，广告字很多的图片放来源，不放大当主视觉。

分享图使用同源短结论、实际范围与真实商品图，沿用大标题、物件拼贴和纸便笺风格，不退化为纯文字摘要。先预览，再实际导出并检查1080×1440 PNG。账号、地址与订单号不放入画面；用户指定的真实图片范围优先。不将AI参考图当真实运行效果。
