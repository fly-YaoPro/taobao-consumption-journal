# 从订单到有意思的发现

目的：从具体购买关系讲出好奇、有趣或有深度的短故事。统计是事实底座，不是最终文案；不能只排列总额、数量、类目就算分析完成。

## 先找阶段，再找细节

先沿时间观察购买重心的变化：是在布置桌面、添置居家物件、持续投入某项兴趣，还是为已拥有的东西维护补配件。有变化才分段，可跨年；不足时不强编。订单数量、采集起点或稀疏程度本身不是人生阶段。阶段之间要有可解释的变化，段内用几笔代表订单撑起来。

有用户确认背景，可以将物件放回读书、租房等阶段；没有背景就只按购买重心命名。重要背景集中问一两点，其余靠已知事实叙事。阶段、物件故事、跨年线索要互补：阶段讲那时生活的重心，物件讲具体小事，跨年线索讲延续与反差。不要把三处全写成相同的复购总结。

## 再做关系清单

按成功父订单核对实付、退款、币种和覆盖，再在商品行找关联。每个候选发现保存：`观察 / 关联来源 / 确认程度 / 还缺什么背景`。挑真正有区别的几条，不强制凑齐以下类型：

- **配套投入**：相机之后的镜头、灯或麦克风；一个爱好最初买什么，后来又添了什么。总额以父订单计一次，不把同单金额重复分摊到各配件。相关不等于同一次使用或购买因果。
- **长期兴趣**：乐器、教材、器材跨年出现。可以写投入延续，不能从“买过”写成“学会了”“练得很好”或“必然吃灰”。
- **具体变化**：同类商品的规格、风格、价格带和补货间隔。重量、数量和支付口径先对齐，不能拿一袋与一箱比较单价。
- **反差**：同一时期两种很不一样的物件，比如低调衣服和花哨宠物服。幽默来自具体东西，不诊断人格或消费能力。
- **成组购买**：同日或相近日期的相关订单可能围绕一个准备事项；缺背景时写“这几件一起出现”，不要直接编搬家、婚育、工作变动。
- **反复出现**：同款/同系列多次购买，给出真实日期或间隔。不把两个不等间隔修成“每年一次”的好看规律。

最高、最贵、最多、第一次和年度增减需完整同口径依据；先检查覆盖状态和日期窗口，当年未结束不能称全年。精选或部分读取用“已收录记录中”，不把漏采解释成购买减少。共享账号和送礼归属不明时，不把每笔订单当目标本人使用；只在确实影响故事的地方一次性询问，不做一串必填问卷。

## 把证据写成短故事

先提出一句有记忆点、能被来源支撑的观察，再用2—5笔订单展开。总览≤200字，主题约40—100字，标题尽量短。具体日期与订单标题放小票、图注或展开来源，不将整段解释复制左右两遍。

以下只示范写法，不是可粘贴的用户经历：

- 模拟事实：相机之后又有灯和麦。可写“买相机只是开头，后面还有一整套。”展开有哪些配套与真实开销；不能写“从此成了摄影师”。
- 模拟事实：同款小零件在三个年份出现。可写“最不起眼的那个，倒成了回头客。”给出三次日期；不能猜设备损坏或搬家。
- 模拟事实：买过教材、几年后又买进阶教材。可写“这个兴趣，隔了几年又回来。”不能把教材当技能证明。

有趣不等于每页一句段子，深度也不靠煽情。少写“你的每一笔消费都定义了你”“生活有了颜色”等通用话。确实没关系的订单不用硬串，医药、成人用品等敏感类别不默认上首页或分享图，不推断疾病、家庭变故或关系。

## 计划从分析里来

从观察推一小步行动，而非给每个类目加“整理”二字。例如一组已有材料可做什么小尝试、确认过的经历可以补记什么、重复配件可怎样核对；整理和盘点只在确实解决本批记录的问题时保留。每条只做一个动作并附来源。无日期依据就 month 留空，由用户安排；不伪装为到期、承诺，不自动购物、付款或创建外部待办。减少无据建议，不随机凑数，也不交付空计划页。
